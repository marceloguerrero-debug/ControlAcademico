### 3️⃣ Comandos de Git para registrar tu Commit propio (Rúbrica)

Ejecuta estos comandos en tu terminal / Git Bash para que el commit quede a tu nombre:

```bash
# 1. Configura tu autoría
git config --global user.name "Daniela Ramos"
git config --global user.email "danielajazminramos5@gmail.com"

# 2. Clona el repositorio
git clone https://github.com/marceloguerrero-debug/ControlAcademico.git
cd ControlAcademico

# 3. Guarda el archivo Estudiante.cs en src/Modelos/Estudiante.cs y edita el README.md

# 4. Agrega los archivos y haz tu commit individual
git add src/Modelos/Estudiante.cs README.md
git commit -m "feat(estudiante): agregar clase Estudiante con herencia de Persona e instrucciones de instalacion en README por Daniela Ramos"

# 5. Sube tus cambios
git push origin main
